# ant!human Bitcrush — VST3 для FL Studio

Небольшой lo-fi / bitcrusher-эффект. Он не кодирует звук в MP3: вместо этого он уменьшает **разрядность аудиосигнала** и имитирует снижение частоты дискретизации. Это даёт характерный цифровой, зернистый и «сломанный» звук.

## Контролы

- **BIT DEPTH (2–16 bit)** — разрядность. Чем меньше значение, тем грубее квантование. Стартовые точки: 12 bit — лёгкое ухудшение, 8 bit — заметный lo-fi, 4 bit — сильный эффект.
- **RATE REDUCTION (1x–64x)** — уменьшение частоты дискретизации через sample-and-hold. `1x` не снижает частоту; большие значения дают более цифровой и ступенчатый звук.
- **DRY / WET (0–100%)** — баланс исходного и обработанного сигнала.

Параметры сохраняются в проекте DAW и поддерживают автоматизацию.

## Получить готовый VST3 без Visual Studio на своём ПК (облачная сборка)

В репозитории уже есть workflow GitHub Actions: `.github/workflows/build-windows.yml`. Он собирает плагин на облачном Windows x64 runner, поэтому Visual Studio локально устанавливать не нужно.

1. Создай пустой репозиторий на GitHub (например, `antihuman-bitcrush`).
2. Загрузи **всё содержимое** этой папки в корень репозитория, включая скрытую папку `.github`.
3. Открой вкладку **Actions** репозитория. Если GitHub попросит разрешить Actions, подтверди.
4. Выбери **Build Windows VST3** → **Run workflow** (или дождись автоматического запуска после загрузки файлов).
5. Дождись зелёного статуса завершения. Внизу страницы запуска, в разделе **Artifacts**, скачай `antihuman-bitcrush-windows-x64` и распакуй ZIP.
6. Скопируй целую папку `ant!human Bitcrush.vst3` в `C:\Program Files\Common Files\VST3\`.
7. Открой FL Studio → **Options → Manage plugins** → **Find installed plugins**.

Если сборка завершилась ошибкой, открой её лог в Actions и пришли сюда текст ошибки — помогу исправить.

## Сборка вручную

В терминале из корневой папки проекта:

```bash
cmake -S . -B build -A x64
cmake --build build --config Release --target AntihumanBitcrush_VST3
```

## Состав проекта

- `Source/PluginProcessor.*` — DSP, параметры и сохранение состояния.
- `Source/PluginEditor.*` — интерфейс с тремя ручками.
- `CMakeLists.txt` — сборка VST3 и Standalone через JUCE.

## Примечание

В архиве находится исходный проект с конфигурацией облачной сборки GitHub Actions, а не готовый Windows `.vst3`-бинарник. Компиляция выполняется на облачном Windows x64 runner; локальная Visual Studio не требуется.
